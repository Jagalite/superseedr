# Security Policy

## Supported Versions

Security fixes are made on `main` and shipped in the next release. Please run the latest release.

## Reporting a Vulnerability

Please do not open a public issue for a vulnerability.

Report it privately through either:

- [GitHub private vulnerability reporting](https://github.com/Jagalite/superseedr/security/advisories/new), or
- email to the security contact, **jagatranvo@gmail.com**.

Include the affected version or commit, steps to reproduce, and the impact you expect. You should get a reply within a
few days. Once a fix is released, the advisory will be published with credit to the reporter unless you ask otherwise.

## Automated Scanning

superseedr is enrolled in Anthropic's [OSS Scanner](https://github.com/anthropics/oss-scanner), which sends its
findings to the security contact above.
